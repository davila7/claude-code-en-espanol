# Claude Code en Español

De la configuración básica al desarrollo avanzado con Claude Code en español.

Este es el repositorio de la comunidad [Claude Code en Español](https://www.facebook.com/groups/1497902218311845/), un grupo público de Facebook con más de 500 mil miembros. Aquí están las reglas del grupo, la guía para publicar y un directorio de proyectos aportados por la comunidad.

Hay gente recién comenzando con Claude y gente muy avanzada. Todos son bienvenidos.

## Empieza aquí

| Quiero... | Lee |
| --- | --- |
| Conocer las reglas del grupo | [REGLAS.md](REGLAS.md) |
| Publicar una pregunta o un aporte | [PUBLICAR.md](PUBLICAR.md) |
| Descubrir proyectos de la comunidad | [PROYECTOS.md](PROYECTOS.md) |
| Aportar un proyecto | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Las reglas en una línea

Respeta a todos, sin odio ni bullying, solo temas de IA y programación, nada de piratería ni venta de cuentas, sin enlaces a otras comunidades, publicaciones en español, da crédito a los autores y no hagas spam. El detalle está en [REGLAS.md](REGLAS.md).

## Recursos para aprender

- [Claude Code en español](https://www.youtube.com/playlist?list=PL2gz3vdpKdfXqvVUE_0qIah5H21kzWmMJ): curso en YouTube.
- [Claude Code Componentes](https://aitmpl.com): componentes listos para usar en tus proyectos.
- [Documentación oficial en español](https://code.claude.com/docs/es/overview): la referencia de Anthropic.

## Mejorar este repositorio

Si encuentras un enlace roto o un error, abre un [issue](https://github.com/davila7/claude-code-en-espanol/issues) o un pull request. Las reglas del grupo solo las cambian los administradores.
